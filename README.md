# Admin Dashboard 

A modern and responsive **Admin Dashboard UI** is built by using **HTML, CSS, Vanilla JavaScript**, thus it mainly focused on UI/UX, layout structure, theme management with any frontend framework.

# 🚀 Features
- Dark/Light theme switch mode.
- Responsive layout.
- Sidebar navigator with toggle.
- Smooth transition and animation.
- Cross-browser compatibility.

# 🎨 Theme Support
- 🌙 Dark mode
- ☀️ Light Mode

# 🛠️ Tech Stack used
- HTML (semantic structure).
- CSS (responsive layout, flexbox, grid).
- JavaScript (ES6+).
- Git & GitHub.
- Vercel (Deployment).
